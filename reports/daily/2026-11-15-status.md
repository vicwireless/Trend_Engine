## Only the owner can do this

Menu names for Etsy, GitHub and Printify are written from memory of those sites, which the engine cannot open; a label may differ slightly.

1. **New Etsy write token.** Steps at the top. Blocks all publishing.
2. **Let the workflows merge their own data PRs (5 min, optional but removes a daily session).** GitHub >
   your profile picture > **Settings** > **Developer settings** > **Personal access tokens** >
   **Fine-grained tokens** > open the token used for `METRICS_SECRETS_PAT` > **Edit** > Repository
   permissions: set **Contents** and **Pull requests** to **Read and write** (keep Secrets) > **Update**.
3. **Open the cloud environment's network to the hosts the engine needs.** In the Claude Code environment
   settings, allow: `openapi.etsy.com`, `www.etsy.com`, `tmsearch.uspto.gov`, `serpapi.com`,
   `api.printify.com`, `printify.com`. Without this the engine cannot do a direct Etsy check, a USPTO
   search, SerpApi sensing or Printify pricing from a session.
4. **Turn on Etsy Ads at $3/day** (after the release is live; Etsy needs a listing to be eligible).
   Etsy > **Shop Manager** > **Marketing** > **Etsy Ads** > set daily budget to **$3.00** > **Start advertising**.
   Then under **Manage advertised listings** switch on only the new game listings (at most 10) and switch the
   planners off. This brings counted spend to exactly the $100 cap.
5. **Trademark spot-check (5 min, optional).** At tmsearch.uspto.gov search FRIENDSGIVING, LEFT RIGHT GAME,
   WHITE ELEPHANT, SECRET SANTA and NICE LIST, live marks in classes 009, 016, 028. Tell the engine what you
   see; it renames anything with a hit the same day and can restore "Friendsgiving" if that mark is dead.
6. **Shop-wide sale.** Shop Manager > **Marketing** > **Sales and discounts** > **New special offer** >
   **Run a sale** > 20% off, whole shop, through 26 Dec. Do this after the release so the new prices are the base.
7. **Record what the tools cost.** Tell the engine the monthly price of Postiz, SerpApi, Claude and eRank
   so the $100 cap counts real spend.
8. **For POD only:** in Printify, **My stores** > **Add new store** > **Etsy** > approve. Then **Account** >
